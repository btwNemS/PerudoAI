Une page classique avec un projecteur.

Ce texte sert de matière visuelle pour tester l’effet. La page reste lisible uniquement dans la zone éclairée, tandis que le reste de l’écran est recouvert par une ombre progressive.

Le principe est simple : on place un calque fixe au-dessus de la page, puis on utilise un dégradé radial CSS. Le centre du dégradé est transparent, la périphérie devient progressivement sombre.

Le JavaScript ne redessine rien. Il modifie seulement des variables CSS : la position du cercle, la taille de la zone entièrement claire, la largeur du fondu et l’intensité de l’ombre.

Déplace la souris sur la page pour déplacer le projecteur. Les curseurs permettent d’ajuster le rendu en direct.

Réglages du projecteur

Astuce : bouge la souris pour déplacer directement le cercle lumineux.
